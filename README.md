# Scheduling Agent — Self-Improving Loop

A patient appointment scheduling agent with an evaluation harness that makes it improve from its own failures.

## Setup

```bash
python -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env          # add your ANTHROPIC_API_KEY
```

## Run the agent (interactive chat)

```bash
python run_agent.py
```

Optional — run with the improved prompt after the eval loop has generated it:

```bash
python run_agent.py agent/prompts/v2.txt
```

## Run the evaluation + improvement loop

```bash
python run_eval.py
```

This runs all 5 scenarios against `v1.txt`, detects failures, patches the prompt into `v2.txt`, re-runs, and prints a before/after comparison table. Full results are saved to `results/run_results.json`.

## Project layout

```
agent/
  scheduler.py        # agent_turn loop with tool dispatch
  tools.py            # mock DB + 4 tool implementations
  prompts/
    v1.txt            # initial prompt (two deliberate gaps)
    v2.txt            # generated by run_eval.py
eval/
  scenarios.py        # 5 scenarios: happy paths + edge cases
  judge.py            # LLM judge + deterministic checks
  harness.py          # patient simulator + run_scenario orchestration
improvement/
  loop.py             # generate_patch → apply_patch → regression check
run_agent.py          # interactive REPL entry point
run_eval.py           # eval + improvement loop entry point
design_note.md        # design choices, before/after scores
```

## What the loop closes

`v1` is missing two instructions:
1. No emergency-interrupt protocol → S03 (chest pain mid-booking) fails.
2. No "offer alternatives" rule → S02 (3pm unavailable) fails.

The improver detects both from failing transcripts and patches `v1.txt` into `v2.txt`. Score moves from **3/5 → 5/5** with zero regressions.
