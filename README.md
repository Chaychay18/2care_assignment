# Scheduling Agent — Self-Improving Loop

A patient appointment scheduling agent with an evaluation harness that makes it improve from its own failures.

## Setup

```bash
python3 -m venv venv && source venv/bin/activate
pip install -r requirements.txt
cp .env.example .env          # add your GROQ_API_KEY
```

Get a free Groq API key at [console.groq.com](https://console.groq.com) → API Keys (no credit card required).

## Run the agent (interactive chat)

```bash
python3 run_agent.py
```

Optional — run with the improved prompt after the eval loop has generated it:

```bash
python3 run_agent.py groq agent/prompts/v2.txt
```

## Run the evaluation + improvement loop

```bash
python3 run_eval.py
```

Runs all 5 scenarios against `v1.txt`, detects failures, patches the prompt into `v2.txt`, re-runs, and prints a before/after comparison table. Full results saved to `results/run_results.json`.

## Project layout

```
agent/
  scheduler.py        # agent_turn loop with tool dispatch
  provider.py         # Groq + Anthropic client abstraction
  tools.py            # mock DB + 4 tool implementations
  prompts/
    v1.txt            # initial prompt (deliberate gap)
    v2.txt            # generated by run_eval.py
eval/
  scenarios.py        # 5 scenarios: happy paths + edge cases
  judge.py            # LLM judge + deterministic checks
  harness.py          # scripted patient turns + orchestration
improvement/
  loop.py             # generate_patch → apply_patch → regression check
run_agent.py          # interactive REPL  (python3 run_agent.py)
run_eval.py           # eval + improvement loop  (python3 run_eval.py)
design_note.md        # design choices, before/after scores
```

## What the loop closes

`v1` is missing an explicit instruction to invoke the booking tool immediately once the patient confirms.
The improver detects this from the failing transcript and patches `v1.txt` into `v2.txt`.
Score moves from **4/5 → 5/5** with zero regressions.
